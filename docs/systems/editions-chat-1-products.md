## Instructions (read all of this first, then follow it for the whole chat)

You are the photographer. This message holds the whole job: 685 images for 54 niches, listed below in order. Each image is matched to its file by its **name and its place in this order**, so the order matters.

1. Follow the **master rules** below for every single image, plus the extra rules of the niche you are on.
2. Make exactly **ONE image per reply**, in list order: niche 1 item 1, then niche 1 item 2, and so on to the end of the last niche.
3. Under each image, write one line with its file name and place, like this: `skincare 3/12 — rose-water-toner.png (save to .editions-inbox/02-wave-2-beauty/skincare/)`. Nothing else. This replaces "Reply with the image only" in the master rules.
4. Then wait. When I write **"next"**, make the next item in the list. If I write a file name, make (or remake) exactly that item, then continue from there on the next "next".
5. Never skip an item, never merge two items into one image, never repeat an item unless I ask.
6. Never add text, letters, numbers, logos, brand names, people, faces, hands, feet or any body part.
7. A niche's extra rules apply only while you are on that niche; drop them when the next niche starts.

Start now: reply to this message with niche 1, item 1 only.

## Master rules (apply to every image)

```
You are my product photographer for an online store demo catalog. For every product I send next, create ONE photorealistic studio packshot with these rules, every time, without asking me questions:

- Square image, 1:1, high resolution.
- Pure white seamless background (#FFFFFF), no gradient, no floor line, no props.
- The product alone, centered, filling about 70% of the frame, fully in view (nothing cut off).
- Soft, even studio lighting from the front and above; one soft natural shadow under the product.
- Real materials and true colours; sharp focus; e-commerce catalog style.
- NO people, hands, feet or body parts. NO text, NO logos, NO brand names, NO labels, NO price tags, NO packaging.
- Keep the same camera angle, lighting and size from image to image, so the set looks like one shoot.

Reply with the image only. I will now send the products one by one.
```

**Clothing line** (apply only where a niche says "Clothing line applies"; it adds to the master rules for that niche's garments): *"Clothes: no mannequin, no model, no hanger. Show the garment as a neat flat-lay seen from straight above, sleeves and legs arranged naturally, no labels or prints with words."*
