<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /connect/onboard | sellerId query param is untrusted; must be validated as existing seller |
| Stripe -> /connect/return | seller param untrusted; DB lookup required before any writes |
| Hono -> Stripe API | Secret key never logged or returned to client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-02-03 | Spoofing | /connect/onboard sellerId param | mitigate | DB lookup validates sellerId exists before creating Stripe account; unknown IDs return 400 |
| T-02-04 | Spoofing | /connect/return seller param | mitigate | DB lookup validates seller exists and has stripeAccountId before any writes |
| T-02-05 | Elevation of Privilege | /connect/* routes public | accept | Routes only perform account linking; wallet insert gated on full Stripe onboarding flow |
| T-02-06 | DoS | Repeated /connect/onboard for same seller | mitigate | Phase 6 UI controls button; each call creates new account (acceptable for MVP) |
| T-02-07 | Information Disclosure | Stripe account ID in DB | accept | stripeAccountId not a secret per Stripe docs; not returned to client by these handlers |
</threat_model>
