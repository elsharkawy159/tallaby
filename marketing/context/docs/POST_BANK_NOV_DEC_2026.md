## How to use

- **Production tools (user rule):** P → **Canva** · C → **Canva**, one multi-page design per pack sharing one design system · R → **Claude builds the video** + **Higgsfield voice-over**. Skits and live-action scenes → **Higgsfield video** (see `SOCIAL_DESIGN_CONTEXT.md` → Production tools).

- **Pillars / gold labels:** P1 **مين إحنا؟** (brand, 18 posts) · P2 **مشكلة وحلها** (problems, 30) · P3 **خدمات طلبي** (store creation help, domain, marketplace exposure, boost package, WhatsApp support; 30) · P4 **ميزة في دقيقة** (tech features, 30) · P5 **اسأل طلبي** (pricing / how to start, 12).
- **Formats:** P = single image 1080×1350 simple style (70) · C = carousel (21) · R = reel / TikTok / Short (29).
- **Headline:** `\n` = line break; the **bold** word goes on the teal highlight box. Shorten any line over ~14 characters at design time.
- **Captions (user rule):** simple, Egyptian Arabic, max one emoji. They end with `https://tallaby.com`; **on Instagram replace the URL with "اللينك في البايو"**.
- **Visuals:** "Dashboard screenshot: …" means the real screenshot from the project files in a phone/laptop mockup. Blur customer data. Posts marked **(verify live)** describe a feature the team must confirm first.
- **Buffer:** Tags column = `P1-brand` / `P2-problems` / `P3-services` / `P4-tech` / `P5-pricing`. Only single images go through the CSV; carousels and reels are posted natively.
- **Status:** mark posts as designed / scheduled / published in the design log (`SOCIAL_DESIGN_CONTEXT.md` §9). When the bank runs low, write new posts in the same format and IDs (e.g. P2-31).
- **Wording:** never "متجرك ببلاش" (orders cost 5 ج.م); use "ابدأ ببلاش" / "التسجيل مجاني". Fix any bank headline that says otherwise at design time.
- **Fulfillment (storage, packaging, delivery, COD collection, customer service, returns) is paused — never mention it (decision 20 Oct 2026).**
- **Facts guard:** 5 ج.م per successful order (never 5%) · بدون رسوم · no card payment · no "cheapest" · no invented numbers or testimonials · طلبي never تالابي · tallaby.com only.
